# Army toolbox — product direction

Discussed 12 November 2026. This records the proposed direction, not an implemented catalogue or permission system.

An Army is a community space assembled from tools. Its host chooses what belongs, sets the shared starting arrangement and expresses the community's identity. Members can move and resize their own view. Platform navigation, joining, reporting and readable controls remain consistent.

Start each new Army with a small template, rather than every possible tool. A future Add a tool drawer can group the catalogue by purpose:

- Conversation: discussions, live chat, polls and questions.
- Expression: StanCam, community galleries and pinned creative contributions.
- Sound: provider-backed playlists, artist links and listening spaces.
- Gathering: events, countdowns and shared prompts.
- Orientation: welcome, about, guidelines, resources and useful links.
- Elsewhere: supported external social previews and direct links.

Each tool should follow the same window behaviour: add/remove, rearrange, resize, minimise, and individual appearance. Presets provide a coherent starting look; the host can make selected tools different. Community content remains connected to its Army, rather than becoming an influencer-style personal feed.

External social tools depend on provider embeds, access and permission constraints. Native StanCam does not depend on Instagram access. A future sponsor/reward tool can use compatible dimensions and clear labelling without taking over the layout, but no advertising system is added here.

The current playground demonstrates five tools: posts, chat, discussions, service-backed music and StanCam. It does not yet provide an Add a tool catalogue, actual host permissions, multi-room creation, shared photo storage or moderation workflows.

The next useful design experiment is the catalogue and a few focused starting templates. It should be possible to build a quiet book club, an expressive music Army or a ridiculous cheese community from the same dependable parts.
